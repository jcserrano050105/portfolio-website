Capstone2025 – 2026Web & mobile app · Team of 5

LearnBridge: Development of a Web and Mobile-Based Academic Support System with AI-Powered Tutor Evaluation and Recommendation for Elementary Learners

A web and mobile platform that connects Filipino parents with verified tutors in English and Mathematics. Tutors pass document checks and an AI-generated certification exam (OpenAI); students take a pre-assessment, and a weighted matching algorithm ranks tutors by weak-subject score, budget, gender and location. Parents book 8-session packages, track progress after every session, and pay through a prepaid wallet that splits fees automatically (90% tutor, 10% platform).

  • React
  • Tailwind CSS
  • Supabase
  • OpenAI API
  • React Native
  • PayMongo

Integration project2026ESSV TECH · Team of 4

KAYA: local skilled-service booking platform

A two-system marketplace that connects households with verified local workers such as plumbers, electricians and cleaners. A Customer & Booking system and a Worker Management system (with an admin role) talk through versioned REST APIs over JSON. Customers describe a problem in plain words, check a worker's Trust Profile, approve a job estimate before work starts, follow live service status, and can pay by cash, GCash or QR. An Emergency Assistance button appears during active service, and every finished job builds the worker's Digital Work Passport.

  • REST API
  • JSON
  • System integration
  • Role-based access
  • GCash / QR payments
